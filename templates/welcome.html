Начало работы

Данных пока нет. Загрузите выгрузку ремонтов из Excel — после этого появятся панель, реестр и список «Требуют внимания».

  1. Откройте Загрузку данных и выберите файл выгрузки (.xlsm или .xlsx).
  2. Нажмите «Проверить структуру» — программа покажет листы и найденные столбцы.
  3. Нажмите «Загрузить данные». Исходный файл не изменяется: программа читает его копию.
  4. Каждый раз после обновления выгрузки в Excel нажимайте «Обновить данные» вверху страницы — так копится история изменений.

По умолчанию загружается лист DL_GR_open_reps, комментарии — из Comments_DB, закрытие исчезнувших ремонтов проверяется по листу актов DL_GR_AVR. Это можно изменить в настройках.
